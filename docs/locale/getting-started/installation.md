# Installation & Setup

Add **Nofinite Locale** (`@nofinite/locale`) to your application.

---

## 1. Package Installation

```bash
# pnpm
pnpm add @nofinite/locale

# npm
npm install @nofinite/locale

# yarn
yarn add @nofinite/locale
```

---

## 2. Flag Stylesheet Configuration

If your application displays flag icons, import the flag stylesheet:

```ts
import '@nofinite/locale/style';
```

Or via CDN `<link>` tag:

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@nofinite/locale/dist/style.css"
/>
```
