# @nofinite/locale

## 2.1.0

### Minor Changes

- a0021b4: Full zero-dependency internationalization toolkit and npm provenance metadata:

  - Added `LocaleProvider`, `useLocale`, and `useTranslation` React hooks at `@nofinite/locale/react`.
  - Added BCP 47 tag parsing and script/directionality helpers at `@nofinite/locale/bcp47`.
  - Added native `Intl` number, currency, date, and relative-time formatters at `@nofinite/locale/format`.
  - Added translator engine and message interpolation utilities at `@nofinite/locale/i18n`.
  - Added npm provenance publishing metadata (`publishConfig.provenance`).
